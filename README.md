# Portfolio Puffer

*A pet app by Astra.*

## Portfolio Puffer

Collect changes worth sharing, shape the update, and mark what is ready.

## How to run

Open [portfolio-puffer-20261008.html](portfolio-puffer-20261008.html) directly in a modern browser. No install, server, account, or network connection is needed.

## What works

- Add and edit update records with purpose-specific fields.
- Search, filter by status, advance a record, and delete with undo.
- Keep entries in this browser's local storage.
- Export a private JSON backup or Markdown worklist.
- Choose among all nine pet moods.

GitHub and LinkedIn connections are planned. Publishing stays with you; this desk keeps the draft and decision.

## Data and limits

Records are stored only in the browser where you enter them. Clearing site data can remove them; export backups. Exported records can contain personal information and must stay outside this source repository. The page does not send entries to a server. The pet's mood is a display choice.
